# Student Portal — розгортання

Це справжній застосунок (не демо в Claude): окремі логіни для тебе (викладачки)
і для кожного учня, дані зберігаються в базі даних. Безкоштовно, ~15-20 хвилин.

## Що знадобиться
- Акаунт на [supabase.com](https://supabase.com) — база даних + логін (безкоштовно)
- Акаунт на [vercel.com](https://vercel.com) — хостинг сайту (безкоштовно)
- Акаунт на [github.com](https://github.com) — щоб Vercel міг узяти код

## Крок 1. Створити базу даних (Supabase)
1. Зареєструйся на supabase.com → **New project**.
2. Дочекайся, поки проєкт створиться (1-2 хв).
3. Зліва відкрий **SQL Editor** → **New query**.
4. Відкрий файл `supabase-schema.sql` з цього проєкту, скопіюй весь вміст, встав у редактор і натисни **Run**.
5. Зайди в **Project Settings → API** — там будуть два значення, які знадобляться далі:
   - **Project URL**
   - **anon public key**

## Крок 2. Викласти код на GitHub
1. Створи новий репозиторій на GitHub (наприклад `student-portal`).
2. Заливай туди всі файли з цього проєкту (можна перетягнути в вебінтерфейсі GitHub, або через git).

## Крок 3. Розгорнути на Vercel
1. Зареєструйся на vercel.com (можна через GitHub-акаунт).
2. **Add New → Project** → обери свій репозиторій `student-portal`.
3. У розділі **Environment Variables** додай:
   - `VITE_SUPABASE_URL` → Project URL з кроку 1
   - `VITE_SUPABASE_ANON_KEY` → anon public key з кроку 1
4. Натисни **Deploy**. За хвилину отримаєш посилання типу `student-portal-xyz.vercel.app` —
   це і є твій сайт.

## Крок 4. Створити свій акаунт викладачки
1. Відкрий сайт → **Зареєструватись** → введи своє ім'я, email, пароль.
2. **Важливо: реєструйся першою**, до того як хтось інший зайде на сайт — перший
   зареєстрований автоматично стає викладачкою, всі наступні — учнями.
3. Supabase за замовчуванням просить підтвердити email листом — лист прийде від Supabase.
   (Це можна вимкнути в Supabase → Authentication → Providers → Email → вимкнути
   "Confirm email", якщо хочеш простіше для учнів.)

## Крок 5. Додати учнів
1. Увійди на сайт як викладачка → вкладка **Students** → **Add student**.
2. Введи ім'я і **точний email**, яким учень користуватиметься для реєстрації.
3. Учень заходить на той самий сайт → **Зареєструватись** → вводить той самий email —
   і його акаунт автоматично прив'яжеться до профілю, який ти створила, з усіма
   заняттями/домашками/словами.

## Локальна розробка (якщо захочеш щось змінювати сама)
```
npm install
cp .env.example .env    # і встав туди свої Supabase-ключі
npm run dev
```

## Якщо щось не працює
Найчастіші причини:
- Забула виконати `supabase-schema.sql` у SQL Editor
- Переплутала local `.env` і Vercel Environment Variables — на Vercel їх потрібно
  додавати окремо в налаштуваннях проєкту
- Зареєструвала учня раніше за себе — тоді він став "викладачкою". Виправити:
  у Supabase → Table Editor → `profiles` → змінити `role` вручну на `student` і
  прописати `student_id`.
